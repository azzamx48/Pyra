The easiest option — real Python, running in your browser, nothing to install.

Open python.org/shell →

Or try replit.com/languages/python3 if you want a code editor with save.

Install Python

  1. Go to python.org/downloads
  2. Download the latest Windows installer
  3. Check "Add Python to PATH" during install — critical!
  4. Open Command Prompt and type python

Or use the Store

Search "Python 3.12" in the Microsoft Store. One click install.

Install Python

  1. Go to python.org/downloads
  2. Download the macOS installer
  3. Run the .pkg file
  4. Open Terminal (⌘+Space, type "Terminal")
  5. Type python3

Or use Homebrew

brew install python

You probably already have it

Open your terminal and type python3. If it works, you're done.

If not, install:

Debian/Ubuntu:

sudo apt install python3

Fedora:

sudo dnf install python3

Arch:

sudo pacman -S python
